# AI 员工与助理平台前端原型

原型采用 Vue 3、TypeScript、Vite、Element Plus、Vue Router 和 Pinia。工作内容、资源连接、员工执行和授权使用预置数据及浏览器本地存储模拟。

## 运行

使用 Node.js 22.12 或以上版本。在本目录执行：

```bash
npm ci
npm run dev
```

打开终端显示的本机地址。`npm run build` 执行 Vue 类型检查和生产构建，生成 `dist/`。`npm run preview` 可预览构建结果。

## 可试用的流程

在工作门户可切换「工作区」和「数字员工」。「工作区」包含新建会话、我的助理、资源库、工作空间和已获授权的工作台。「数字员工」包含员工目录和任务总览。

- 从「新建会话」选择默认助理、个人配置的助理或获准使用的共享助理，发送工作内容，把回复产物保存到工作空间。获授权的「ET 设计助理」也可在此选择。工作空间支持上传、预览、下载和引用本地文件。
- 在「资源库」按类型和来源查找资源，新增个人资源，再在「我的助理」配置中选用。
- 在「员工目录」联系已启用且获使用授权的数字员工，沟通或交办任务。打开员工卡片的任务入口，可直接查看该员工在任务总览中的获授权记录。
- 在「任务总览」切换「全部任务」和「我交办的任务」。用员工姓名、岗位或任务标题搜索，也可按来源、状态和时间筛选。打开详情查看来源、进展和结果。交办任务需要补充信息时，可在详情提交补充内容。自主任务按员工使用权和任务业务访问权限显示。
- 打开「工程造价工作台」，切换项目，预览楼栋体量，编辑造价台账或将计价结果写入计算记录。
- 打开「招投标工作台」，查询示例公告与拟建项目，预览并确认初筛规则，再分析或人工复核机会。在「报告交付」生成快照，可下载 CSV 或打印为 PDF。
- 打开「设计工作台」，在三屏画布选择按钮或标题，可直接改字、改样式、加标注，也可在设计对话输入修改要求并应用建议。「试用」可走完加购、结算和查看订单，「导出」提供带页面跳转的 HTML 和设计配置 JSON。
- 打开「ET 设计工作台」，可从个人工作空间选择已有 ASCII DXF，也可直接上传、拖入本地文件或打开示例图纸。拖动框选实体后，可在「基础能力」查看图层和实体信息，或在「智能问图」基于当前范围提问。「格式转换」可下载原始 DXF，或把当前可预览的实体导出为 HTML 或 SVG。
- 打开「外贸工作台」，编辑柜型或车型与货物明细后开始计算，重播装柜图、筛选货物并比较候选柜型。生成的装箱单按实际装入数量汇总，可编辑抬头、打印 A4、下载 CSV，也可带回装柜计算。草稿按账号保存。
- 打开「项目管理工作台」，切换项目，查看今日任务和逾期，在「本周」查看跨日排期与里程碑，在「任务」调整进展或筛选，在「想法」将想法转为任务。项目助理可梳理优先事项、交付风险和复盘材料，记录按账号保存。
- 在工程造价、招投标、设计、ET 设计、外贸或项目管理工作台的智能处理区切换助理。进入时优先选择获授权的配套组织助理，配套助理不可用时可用内置助理继续操作工作台。切换后沿用当前业务对象，智能处理按工作台的本地规则演示。
- 使用获配置试用权或发布权的演示账号，在原型地址打开 `/#/employees/manage` 进入员工维护页面。组织管理员可在管理后台「数字员工」新建草稿，从员工详情选择「前往工作门户配置」或「查看运行记录」，并在后台启用已发布员工及分配使用权。配置详情支持按授权试用、记录培训反馈、发布稳定版本及查看共同负责人。
- 在员工详情的「工作规则」选择事件类型并指定业务负责人，可填写匹配关键词。可用设计交付专员的「图纸更新核对」示例规则，提交「文件更新」事件，内容填写「南区产线图纸已更新」。在「运行记录」查看命中的规则、模拟进展和结果。规则与运行记录保存在当前浏览器。
- 在管理后台打开「工作台与助理」，切换「工作台」和「组织助理」查看各自的管理列表。打开「ET 设计工作台」或「ET 设计助理」详情可查看和设置配对。给尚未获得使用权的成员新增分配时，配套项默认勾选，保存前可取消。从「组织与成员」的成员详情新增分配时也可体验。切换到相应成员账号，在工作门户查看获分配的工作台和助理。「文档整理助理」可单独分配。
- 在管理后台打开「组织资源」，按模型、技能、MCP、知识、工具筛选，并打开资源详情查看授权与接入情况。

演示数据保存在当前浏览器的 `localStorage`。可使用无痕窗口开始一份新的演示数据。个人工作空间文件上传限单文件 1 MiB，当前账号文件总量 2 MiB。ET 图纸在页面内本地处理，单文件上限 10 MB。模型、MCP、业务连接及账号授权均为前端模拟，真实服务接入参见 [PRD](../dsh_platfrom_prd.md)。
