# AI 员工与助理平台前端原型

原型采用 Vue 3、TypeScript、Vite、Element Plus、Vue Router 和 Pinia。工作内容、资源连接、员工执行和授权使用预置数据及浏览器本地存储模拟。`npm run test:admin` 可执行后台核心规则回归检查。

## 运行

使用 Node.js 22.12 或以上版本。在本目录执行：

```bash
npm ci
npm run dev
```

打开终端显示的本机地址。`npm run build` 执行 Vue 类型检查和生产构建，生成 `dist/`。`npm run preview` 可预览构建结果。

## 可试用的流程

从工作门户顶部可切换「工作区」「AI 员工」和「资源库」。工作区包含新建会话、我的助理、文件中心和已获授权的工作台。AI 员工区包含员工目录和任务总览。林知远可从右上角进入管理后台，首次默认打开「运行监管」中的「运行总览」。「组织管理」提供组织与成员、角色与权限。「能力与资源」提供工作台与助理、AI 员工及组织资源。「运行监管」提供运行总览、助理与工作台运行、用量与费用和 AI 员工运行。「平台管理」提供插件接入、系统连接和变更记录。本次会话内，切回已打开的区域或在工作门户与管理后台间往返时，可继续访问各自最后打开的页面。

- 在「运行总览」选择时间与部门，查看活跃成员、助理请求、工作台操作、执行失败、Token 和估算费用。当前依赖问题置顶，按问题归并并列出影响范围，区分运行异常和接入待检测；全组织当前状态不随历史筛选变化。可用版本更新在能力目录及详情查看。统计、最近运行、运行明细、用量费用和能力详情共用记录；预置记录首次生成后保留，刷新只重新汇总。
- 在「助理与工作台运行」搜索并按时间、执行状态筛选；「更多筛选」展开部门、模型、能力和类型。支持分页、空结果清除筛选及筛选地址保留。点击记录核对执行结果及依赖当前状态，再查看能力及依赖。历史失败记录不会因依赖恢复而被改写。原型记录不含会话正文或业务文件。
- 在「用量与费用」按时间、部门、模型和能力筛选，切换按模型／能力汇总，再打开同范围运行记录。工作台纯访问不计入模型用量；预置请求按示例单价估算，原型新操作不虚构 Token。
- 在「插件接入」按启停与版本、依赖与影响、变更记录查看。通过「更多操作 → 演示加载失败」查看受影响能力，再「模拟检查加载」恢复。启停和切换版本先预览影响；启用或切换后需要检查加载。添加插件只登记演示元数据，不安装插件。
- 在「系统连接」添加五类连接，详情按连接与凭据、影响范围、检测记录、变更记录分组。模型网关通过「更多操作 → 演示连接异常」模拟异常，回运行总览可看到模型和助理的关联异常，重新检测通过后当前异常清除。
- 在能力详情按授权与职责、启停与版本、接入与配套、变更记录分组办理。使用授权、维护／共同负责人和发布人员合并保存；角色授权来源继续独立保留。列表筛选进入详情再返回仍保留。主要编辑表单修改后取消或离开，可选择继续编辑或放弃。
- 在「组织与成员」先选择部门和筛选成员，勾选成员后出现批量角色和直接授权操作；成员详情的操作随当前分组切换。「角色与权限」集中角色权限、已分配成员和变更。「变更记录」可组合时间、对象类型、操作类型及操作人，展开核对前后内容。
- 在「AI 员工运行」按时间、员工、发起方式、状态及连接查询；统计与筛选任务范围一致，时间按任务创建时间计算，执行次数包含所选任务的历次执行。业务复核和重试继续在工作门户按业务权限办理。
- 连接编辑可选择环境变量回退、组织共享、成员本人或无需凭据。只填写虚构演示值，保存后输入框清空，只保留虚构引用；留空保留已有引用。组织凭据缺失时检测异常；成员凭据分别绑定，不为其他成员提供调用身份。真实凭据存储与鉴权尚未实现。
- 从「新建会话」进入时，输入卡上方默认选中「通用助理」和「默认工作目录」（「我的文件」根目录）。选择子目录时显示末级目录名，悬停可查看完整路径。发送前可更换助理和目录，发送后在页头查看已绑定的两项。输入 `@` 或点击「+」可查找并引用绑定目录中的文件，会话右侧文件树也使用该目录。点回复下方的产物卡可在右侧栏预览，点「编辑与保存」可保存到绑定目录。共享目录仅可查看时可引用文件，具备编辑权限时可保存产物。
- 从工作区侧栏的「会话」点击搜索图标查找标题、目录、助理或消息内容。点「会话列表展示设置」可切换分组、排序和归档筛选。拖动普通会话或用「更多操作」上移、下移，顺序实际改变后会自动进入「手动排序」。切回「最近更新」会清空手动顺序，并按最后一次发送用户消息的时间排序。以林知远身份归档一条会话，再切换到「仅显示已归档」查看历史并「取消归档」。收起侧栏后，可从「会话」浮层使用同样的操作。
- 「我的助理」默认打开「全部」，可切换「我的」查看通用助理及个人助理，或切换「共享」查看组织和其他成员共享给你的助理。「全部」和「我的」可新建及配置个人助理。获授权的成员可从「全部」和「共享」进入「组织助理配置」。
- 在「文件中心」切换到「共享空间」，「空间范围」下拉框默认选中「全部」，可看到本人创建和获授权加入的空间。以林知远身份选择「我加入的」，可体验查看和编辑两种权限。林知远在「我创建的」里看到 ET-052，周可欣在「我加入的」里看到同一空间及其「可编辑」权限。按空间名或所有人搜索，输入 ET-052 也可找到图纸评审空间。点击卡片可进入文件目录。「我的文件」和共享空间的目录均以列表展示，支持搜索当前目录。从共享目录通过面包屑返回空间列表时，会恢复范围和搜索关键词。成员可预览或下载共享图纸、从已确认的检查清单定位图纸依据，并查阅获授权的交付结果。空间成员和工作台权限分别校验。
- 在「共享空间」点击「新建共享空间」，填写名称，可按姓名或部门选择成员并逐人设置查看或编辑权限。创建后会切到「我创建的」，已选成员在「我加入的」里立即看到该空间。鼠标悬停卡片可看到「更多操作」，通过键盘聚焦或在触屏设备上也能操作。创建者可以重命名、管理成员或删除空间。通过「管理成员」可继续邀请、调整权限或移除成员。查看成员可预览和下载，编辑成员还可新建文件夹和上传文件。受邀成员可在卡片的「更多操作」中退出空间，已上传的文件会保留在空间内。
- 在目录列表的操作列，可通过图标直接重命名、移到同一空间的其他目录，或确认删除。共享空间仅编辑成员和创建者可执行这些操作，ET-052 的内置评审目录和派生资料由评审流程维护。点击文件名可查看并下载文件。
- 在工作区打开「自动化任务」。点「新建」进入会话，可发送「每周五下午 5 点提醒我整理周报。」；也可在「新建」旁的下拉菜单选择「手动配置」，直接设置名称、计划和指令。两种方式创建的任务都在同一列表显示，可按状态筛选或搜索。打开详情可以查看规则和模拟运行记录，更多操作里可暂停、恢复、模拟运行或删除任务。
- 在「资源库」选择资源类型，再切换「全部」「我的」和「共享」。「共享」包含组织或其他成员共享给本人的资源。可以新增个人资源，再在「我的助理」配置中选用。
- 在「员工目录」联系已启用且获使用授权的 AI 员工，沟通或交办任务。打开员工卡片的任务入口，可直接查看该员工在任务总览中的获授权记录。
- 在「任务总览」切换「全部任务」「我交办的任务」和「待我处理」。可按员工、来源、状态和时间筛选，也可搜索任务。「待我处理」汇总普通交办中需本人补充的事项及由本人接手的场景任务。打开原详情可处理待办并查看进展。自主任务按员工使用权和任务业务访问权限显示。
- 打开「工程造价工作台」，切换项目，预览楼栋体量，编辑造价台账或将计价结果写入计算记录。
- 打开「招投标工作台」，查询示例公告与拟建项目，预览并确认初筛规则，再分析或人工复核机会。在「报告交付」生成快照，可下载 CSV 或打印为 PDF。
- 打开「设计工作台」，在三屏画布选择按钮或标题，可直接改字、改样式、加标注，也可在设计对话输入修改要求并应用建议。「试用」可走完加购、结算和查看订单，「导出」提供带页面跳转的 HTML 和设计配置 JSON。
- 打开「ET 设计工作台」，可从「我的文件」选择已有 ASCII DXF，也可直接上传、拖入本地文件或打开示例图纸。拖动框选实体后，可在「基础能力」查看图层和实体信息，或在「智能问图」基于当前范围提问。「格式转换」可下载原始 DXF，或把当前可预览的实体导出为 HTML 或 SVG。
- 打开「外贸工作台」，编辑柜型或车型与货物明细后开始计算，重播装柜图、筛选货物并比较候选柜型。生成的装箱单按实际装入数量汇总，可编辑抬头、打印 A4、下载 CSV，也可带回装柜计算。草稿按账号保存。
- 打开「项目管理工作台」，切换项目，查看今日任务和逾期，在「本周」查看跨日排期与里程碑，在「任务」调整进展或筛选，在「想法」将想法转为任务。项目助理可梳理优先事项、交付风险和复盘材料，记录按账号保存。
- 在工程造价、招投标、设计、ET 设计、外贸或项目管理工作台的智能处理区切换助理。进入时优先选择获授权的配套组织助理，配套助理不可用时可用内置助理继续操作工作台。切换后沿用当前业务对象，智能处理按工作台的本地规则演示。
- 在 AI 员工侧栏打开「我的员工分身 → 员工管理」。林知远可点击「新建 AI 员工」，填写名称和岗位职责后创建草稿。进入详情后保存岗位配置，在「试用与培训」分别运行正常和人工接手样本并记录反馈，再在「版本管理」发布。点击「前往管理后台启用」，由管理员启用已发布版本并按需分配使用权。员工卡片显示生效版、待启用版及本人待办，操作按当前账号获授的权限开放。
- 在「岗位配置」的「工作规则」选择事件类型和业务负责人，可填写匹配关键词、工作内容、交付物及人工接手条件。设计交付专员的「图纸更新核对」可用「文件更新」事件试跑，内容填写「南区产线图纸已更新」。试跑结果在「试用与培训 → 规则试跑记录」查看。正式任务在「我的员工分身 → 运行监管」查看，按本人负责的 AI 员工及业务权限开放。
- 在管理后台打开「组织与成员」，从左侧部门树选择「客户服务」。在「更多操作」选「分配给本部门」，将 ET 设计工作台及配套助理直接分配给当时的在用成员。在宋予安的详情可查核「使用授权」和「负责维护」。在「调岗交接」中，将他调入「设计部」，按需收回直接授权，并将售后服务专员的维护职责交给周可欣。返回部门目录、成员详情及变更记录核对结果。之后新增或调入的成员单独分配。
- 在「角色与权限」新建业务角色，勾选 ET 设计工作台时默认勾选配套助理，可取消；保存后从角色列表或详情「分配成员」。在「组织与成员」也可从成员详情「分配角色」，或选中多名成员批量分配。确认前查看影响预览，分配后在成员详情核对角色和使用授权来源，再切换账号体验工作门户。
- 在「角色与权限」选择内置组织管理员或自定义部门管理角色，为周可欣分配并指定「客户服务」和可分配的能力。切换到周可欣可体验受限的部门管理入口。自定义管理角色采用全组织、部门管理、运行查看或平台接入预设。
- 将「运行运营人员」分配给周可欣后，切换账号可查看全组织运行、用量和只读能力依赖；不能进入组织管理或操作连接。分配「平台运维人员」可管理插件与连接，并查看能力影响及相关变更，不能调整成员使用权。每人仍只持有一个管理角色。
- 用系统管理员在后台「能力与资源 → 工作台与助理」打开工作台详情，在「工作台配置」修改名称、说明和组织资源依赖，点击「保存配置」立即生效，并可在变更记录核对前后内容。已启用工作台变更资源依赖时先校验可用性，失败保留原配置。使用授权、启停、配套助理和系统连接在同一详情办理。工作台不单独发布配置版本，功能版本统一在「平台管理 → 插件接入」管理，升级不会替换管理员设置。旧演示数据自动沿用原已生效配置并移除配置版本字段。工作门户只保留业务使用入口，真实插件安装和升级尚未接入。
- 成员详情可查账号标识、演示登录方式和「授权与成员变更」。角色、能力、插件与连接详情可按对象标识进入变更记录。
- 角色详情提供权限配置和已分配成员。业务角色可停用、启用或移除成员，直接授权及其他角色继续有效。修改角色后通过分配确认同步，成员列表显示待同步状态。分配记录、权限快照和变更记录随浏览器本地存储保留。
- 在管理后台打开「工作台与助理」，切换「工作台」和「组织助理」查看各自的管理列表。打开「ET 设计工作台」或「ET 设计助理」详情可查看和设置配对。给尚未获得使用权的成员新增分配时，配套项默认勾选，保存前可取消。从「组织与成员」的成员详情新增分配时也可体验。切换到相应成员账号，在工作门户查看获分配的工作台和助理。「文档整理助理」可单独分配。
- 在管理后台打开「组织资源」，按模型、技能、MCP、知识、工具筛选，并打开资源详情查看授权与接入情况。

## EnterpriseAI 场景样板

### ET-052 图纸评审、交接与异常恢复

1. 用周可欣打开 ET 设计工作台的「打开图纸评审」。切换 V1、V2，可框选 V2 实体。在「智能问图」生成检查清单，定位一项依据，改写结论并「确认并保存到 ET-052」。发布 V2 后，在「查看发布与交付」打开核对任务。
2. 默认「项目系统（演示）」待检测。切换林知远，打开「AI 员工 → 我的员工分身 → 运行监管 → 待跟进」，点击 ET-052 的执行异常记录。抽屉显示原任务编号、指定接手人和首轮失败。点「前往后台恢复连接」，在管理后台「模拟恢复连接」，再点「返回工作门户」。
3. 从同一个抽屉「打开任务详情」后点击「重试任务」，待进入「待复核」填写意见并「确认复核」。回到运行监管可回看同一任务的失败、重试和写回记录。从任务「打开业务记录」可验证 V2 已写回，获授权成员也可在共享空间继续查看交付结论。
4. 从 ET-052 选择「交办核对」可提交另一项关联任务，并在原沟通及「我交办的任务」查看。来源入口可以选工作门户、企业消息（模拟）或业务系统（模拟）。

### 招投标从机会筛选到立项

1. 林知远打开招投标工作台的示例机会 ZB-26071，查看候选依据，点击「模拟定时筛选」，打开生成的任务。
2. 依次切换宋予安、周可欣、林知远。每人从「任务总览 → 待我处理」打开同一条任务，分别填写技术核实、商务核实和立项意见。林知远确认立项后打开业务记录，检查原机会是否显示「已立项」和已写回的结论。

| ET 图纸评审 | 评审编号、图纸及材料清单版本、文件更新规则、设计交付专员、项目系统连接 | 业务负责人可从任务定位所查版本和依据，提交复核后结论出现在原评审记录。模拟连接恢复后，重试沿用任务编号并追加执行记录。 |
| 招投标机会 | 机会编号和公告快照、筛选规则、综合事务专员、示例模型网关 | 技术、商务和投标负责人各自能执行当前步骤。最终结论回到同一机会，两个人工核实记录可回查。 |

交付到客户环境时需绑定客户的业务对象映射、知识与规则、连接和凭据、业务负责人及验收样本。当前样板在同一浏览器内模拟，未来试点可记录人工复核耗时、交接等待和结果准确性。

演示数据保存在当前浏览器的 `localStorage`。可使用无痕窗口开始一份新的演示数据。文件中心上传限单文件 1 MiB，个人文件和共享上传各有 2 MiB 的浏览器存储上限。ET 工作台导入的图纸在页面内本地处理，单文件上限 10 MB。插件加载、模型、MCP、业务连接、凭据引用及账号授权均为前端模拟，真实服务接入参见 [产品需求与待确认事项](../PRD/EnterpriseAI_Platform_PRD.md#待确认事项清单)。
